## One world — how the six inspirations are unified

- **Location:** One grand Chettinad-style Tamil ancestral home decorated for the engagement; camera journeys inner puja nook -> window floor -> open-sky courtyard -> swing side hall -> garlanded mandapam corridor -> main studded door -> front-hall arch -> close-up card.
- **Palette:** dark walnut/teak wood, burnished brass gold, rose red & deep pink, jasmine white, banana-leaf green, cream paper, maroon (emblem/saree only)
- **Lighting:** warm golden late-afternoon sun shafts + amber brass-lamp glow; deep warm wood shadows; gentle bloom; dust motes
- **Lettering:** floating warm-ivory Tamil display type with thin antique-gold bevel and soft glow; on cards, embossed rose-gold foil
- **Recurring Props:** brass kuthuvilakku & hanging chain lamps, red/pink rose garland strands, jasmine strings/buds, banana plants/leaves, engraved gold plate, paisley-foil hero card, gold rings
- **Camera Language:** one continuous journey; alternating RIGHT/LEFT pivots and arcs with near-foreground wipes (pillar, garland strands, banana plant, lamp), fast burst then slow-motion settle, continuous petal drift; finale slow-motion push-in.
- **People:** none by default (hands appear only as flat ivory-gold line art on the title)

## Tamil spelling check notes

- நிச்சயதார்த்த அழைப்பிதழ் — compound form (the inspiration's “நிச்சயதார்த்தம் அழைப்பிதழ்” is also seen, but the dropped ம் is the more correct compound).
- நல்லாசியுடன் = நல் + ஆசி + உடன்; நன்னாளை = நல் + நாள் + ஐ — standard sandhi.
- மணமகனின் / மணமகளின் பெற்றோர் — genitive form (cleaner than bare மணமகன் பெற்றோர்).
- திருநிறைச்செல்வன் / திருநிறைச்செல்வி — traditional invitation honorifics (bride alt: திருவளர்ச்செல்வி).
- Save-the-date rendered as “இந்த நன்னாளை / நினைவில் கொள்ளுங்கள்” (natural, warm) rather than a literal calque; alt “தேதியைக் குறித்துக்கொள்ளுங்கள்”.
- Times: காலை (morning), மதியம் (noon/afternoon), மாலை (evening), இரவு (night) + மணி; digits are Arabic numerals as in modern Tamil print.
- “ஃபைண்ட் மை இன்வைட்” = FindMyInvite in Tamil script (ஃப for F). Optional.
- Avoided “ஸ்ரீ” (Grantha ligature) by default because image models mis-render it; easy to add if wanted.
